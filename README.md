# Symptom Tracker
A simple, mobile-friendly symptom and context tracker. Data is stored locally in the browser and can be exported as CSV or backed up/restored as JSON.

## GitHub Pages
Upload `index.html`, `style.css` and `app.js` to the root of a repository named `symptom-tracker`, then enable GitHub Pages from the repository Settings → Pages using the main branch/root folder.

## Important
GitHub hosts only the app code. Personal records are not written to the repository. Browser-local data can be lost if site data is cleared, so use the JSON backup regularly.
